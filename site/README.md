# AWS Static Website

A responsive static website built using HTML, CSS and JavaScript.

## AWS Services
- Amazon S3
- AWS CodePipeline
- AWS CodeBuild
- AWS CodeConnections

## Deployment
1. Push website files to GitHub.
2. Connect the repository to AWS CodePipeline.
3. Configure CodeBuild to use buildspec.yml.
4. Deploy the pipeline artifact to an S3 bucket.
5. Test the deployed website.

## Local Testing
Open index.html in your browser.
